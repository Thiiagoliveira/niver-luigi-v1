# Quadros originais do Luigi

Origem: https://www.spriters-resource.com/nintendo_switch/papermariotheorigamiking/asset/136282/

Jogo e personagem: Nintendo, *Paper Mario: The Origami King*. Publicação do pacote: Fawfulthegreat64; contribuição: Penky.

Os nove PNGs em `originals/` são cópias sem alterações de `Individual frames/1/R/`. Consulte `frames.json` para o mapeamento de índices do atlas. O atlas usa margens transparentes uniformes e alinhamento pela base, sem alterar as proporções do desenho. Para reconstruí-lo, execute `scripts/prepare-sprites.py` com o ZIP original.
